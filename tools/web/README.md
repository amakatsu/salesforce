# 📝 Excel単語照合ツール - Webインターフェース

画面項目定義と単語帳を照合し、**物理名を自動提案**するWebツールです。
ブラウザから簡単に使えて、LLMが最適な命名を提案します。

## ✨ できること

このツールは、以下の作業を自動化します：

1. **画面項目名と単語帳の照合**
   - 例：「顧客名」→ 単語帳の「顧客」と一致を検出

2. **物理名の自動提案**
   - 例：「回収稟議番号」→ `kaishuRingiNo` を提案

3. **未登録語の検出**
   - 単語帳にない語を自動的にリストアップ

4. **一致状況の可視化**
   - 完全一致/部分一致/一致なしを色分け表示

## 🚀 主な機能

- 🌐 **ブラウザから利用可能** - インストール不要、URLにアクセスするだけ
- 📁 **ドラッグ&ドロップ対応** - ファイル名は自由（左右の区別で自動判定）
- 📊 **リアルタイム進捗表示** - 処理状況を逐次確認
- 💾 **結果をExcelでダウンロード** - 色分けされた結果ファイル
- 🔑 **柔軟な設定** - APIキー・列名をブラウザで簡単設定
- 🐳 **Docker対応** - 1コマンドで起動可能

## 🎯 クイックスタート（3ステップ）

### ステップ1️⃣: Dockerで起動

```bash
cd word-web
docker-compose up -d
```

### ステップ2️⃣: ブラウザでアクセス

```
http://localhost:8501
```

### ステップ3️⃣: APIキーを設定して使い始める

1. サイドバーで「APIキー」と「ユーザID」を入力
2. 画面項目定義ファイルをアップロード（左側）
3. 単語名一覧ファイルをアップロード（右側）
4. 「🚀 照合実行」ボタンをクリック

**これだけで使えます！**

## ⚙️ 詳細設定（オプション）

### 環境変数ファイル（.env）で事前設定

API情報を毎回入力したくない場合は、`.env`ファイルを作成：

```bash
# word-web/.env を作成

# API設定
OPENAI_BASE_URL=https://mufg-openai-api.azure-api.net/aoai001/openai/deployments/ptu
OPENAI_HEADERS_JSON={"api-key":"your-key-here","apim-user-id":"YOUR_ID"}

# プロキシ設定（社内ネットワーク等で必要な場合）
HTTP_PROXY=http://proxy.example.com:8080
HTTPS_PROXY=https://proxy.example.com:8080
```

`.env`ファイルがあれば、サイドバーの入力欄に自動で設定値が入ります。

## 📖 詳しい使い方

### 1️⃣ ファイルのアップロード

| アップロード場所 | ファイル内容 | ファイル名 |
|---|---|---|
| **左側** | 画面項目定義 | 任意（例: `設計書.xlsx`） |
| **右側** | 単語名一覧 | 任意（例: `辞書.xlsx`） |

**ポイント:**
- ファイル名は自由です（左右の区別で自動判定されます）
- 複数ファイルをまとめてアップロード可能
- ドラッグ&ドロップでもOK

### 2️⃣ 設定の確認（サイドバー）

#### 🔑 API認証情報
- **APIキー**: Azure OpenAI APIのキー
- **ユーザID**: API ManagementのユーザID

#### 📋 Excel列名設定
- **画面項目定義の列名**: デフォルト「項目名称」
- **単語帳の列名**: デフォルト「論理名」

#### 🔧 LLM設定（上級者向け・通常は変更不要）
- Max Tokens、Temperature、類似度しきい値など

### 3️⃣ 照合実行

「🚀 照合実行」ボタンをクリック
- 処理中は進捗バーで状況をリアルタイム確認できます
- 例: 「🔄 照合処理を実行中... (45/100件 処理済み)」

### 4️⃣ 結果の確認とダウンロード

#### 📊 処理サマリ
5つの指標を表示：
- **合計**: 全体の項目数
- **完全一致**: 単語帳に単一語として登録済み
- **完全一致（部品）**: 分解した全ての語が単語帳に存在
- **一部一致**: 一部の語が未登録（⚠️確認が必要）
- **一致なし**: 全て未登録（⚠️単語帳追加が必要）

#### 📋 結果プレビュー
先頭10件をブラウザで即座に確認

#### 📥 ダウンロード
「📥 結果をダウンロード (Excel)」ボタンで`match_result.xlsx`を取得
- 一致状況ごとに色分け表示
- 未登録語のリスト付き

## 🔧 判定ロジックの詳細

このツールは以下の5ステップで判定を行います：

### ステップ1: 正規化と完全一致チェック
- 全角/半角、大文字/小文字を統一
- 単語帳と完全一致する場合 → **即座に「完全一致」** ✅（LLM未使用）

### ステップ2: 候補語の抽出
- 類似度スコア（デフォルト0.72以上）で候補を絞り込み
- 複合語対策として単語分解も実施

### ステップ3: 高スコア完全一致の再チェック
- 類似度が1.0の場合 → **「完全一致」と判定** ✅（LLM未使用）

### ステップ4: LLMによる詳細判定
LLMが以下を判定：

| 判定結果 | 説明 | 例 |
|---|---|---|
| **完全一致（部品ごと）** | 分解した全ての語が単語帳に存在 | 「回収稟議番号」→「回収」+「稟議番号」 |
| **一部一致** | 一部の語が単語帳にあり、一部は未登録 | 「顧客担当者名」→「顧客」と「名」はあるが「担当者」は未登録 |
| **一致なし** | どの語も単語帳に存在しない | - |

### ステップ5: 物理名の提案
- 候補語の物理名を組み合わせて lowerCamelCase で提案
- 未登録語は命名規則に従って自動生成
- 文字数制約（8文字推奨、最大15文字）を考慮

## ❓ トラブルシューティング

### 🔴 ポート8501が既に使用されている

`docker-compose.yml`のポート番号を変更：

```yaml
ports:
  - "8502:8501"  # 左側の番号を変更
```

その後、`http://localhost:8502`でアクセス

### 🔴 API接続エラーが出る

**原因1: APIキー/ユーザIDが間違っている**
- サイドバーで正しい値を入力しているか確認

**原因2: プロキシ設定が必要**
- `.env`ファイルに以下を追加：
```bash
HTTP_PROXY=http://your-proxy:port
HTTPS_PROXY=https://your-proxy:port
```

**原因3: ネットワークエラー**
- コンテナログを確認：
```bash
docker-compose logs -f word-web
```

### 🔴 ファイルアップロードが失敗する

- Streamlitのデフォルト制限は200MBです
- 大きなファイルの場合は分割してアップロードしてください

### 🔴 処理が遅い・固まる

- 大量データ（1000件以上）の場合、数分かかることがあります
- 進捗バーで状況を確認してください
- バックグラウンドで並列処理中のため、ブラウザはそのまま待機
