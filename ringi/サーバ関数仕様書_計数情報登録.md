## 機能概要

計算結果の各DTOと案件情報をもとに、計数案件番号の取得・基準日の決定を行い、計数情報データの登録/更新および禀議書（共通）の計数取得要否更新を一括で行う。

|---|---|---|
| String | 案件番号 |  |
| String | 補正区分 |  |
| String | 店番 |  |
| String | 取引先番号 |  |
| String | 禀査番号 |  |
| 計数計算結果DTO | 計数計算結果 | 計数計算の戻り値（読み取り専用）。一般与信状況計算結果DTO・本件後保全状況計算結果DTO・科目明細当月増減額計算結果DTO・保全率計算結果DTOを含む。構造詳細は [DTO構造設計](DTO構造設計.md) 参照 |

## 処理仕様

1. 計数案件番号取得
   案件番号と補正区分をキーに禀議共通情報を取得し、計数案件番号を取得する。

   リポジトリ呼出

   | 区分 | 値 |
   |---|---|
   | リポジトリ名 | 禀議共通リポジトリ |
   | メソッド名 | 案件番号と補正区分で検索(案件番号, 補正区分) |
   | パラメータ1 | 案件番号 = 引数.案件番号 |
   | パラメータ2 | 補正区分 = 引数.補正区分 |
   | 戻り値 | 禀議共通エンティティ |

   1. 取得レコード件数が0件の場合
      業務例外（YUSGS5019S-E）をスローする。

   1. 正常に禀議共通情報を取得できた場合
      取得した禀議共通情報エンティティから計数案件番号を取得し、後続処理で使用する。

1. 基準日設定
   取得した計数案件番号と補正区分をキーに禀議共通情報を再取得し、基準日の元となる取引日を取得する。
   取引日が未設定の場合は営業日を取得し、基準日として採用する。

   リポジトリ呼出

   | 区分 | 値 |
   |---|---|
   | リポジトリ名 | 禀議共通リポジトリ |
   | メソッド名 | 案件番号と補正区分で検索(案件番号, 補正区分) |
   | パラメータ1 | 案件番号 = ステップ1で取得した計数案件番号 |
   | パラメータ2 | 補正区分 = 引数.補正区分 |
   | 戻り値 | 禀議共通エンティティ |

   1. 取得レコード件数が0件の場合
      業務例外（YUSGS5019S-E）をスローする。

   1. 正常に禀議共通情報を取得できた場合
      取得した禀議共通情報エンティティから取引日を取得する。

   1. 取得した取引日が未設定の場合
      当日営業日取得機能を呼び出し、当日営業日を取得する。

      共通ライブラリ呼出

      | 区分 | 値 |
      |---|---|
      | 機能分類 | カレンダー共通機能 |
      | 機能名称 | 当日営業日取得 |
      | パラメータ | なし |
      | 戻り値 | 当日営業日 |

   1. 基準日を設定する
      取得した取引日、または当日営業日を基準日として設定する。

1. 計数情報データ更新
   計数計算結果DTOから各サブDTOを取り出し、案件情報・基準日とともに計数情報を保存する。
   初回の計数情報登録時は追加を行い、既存データがある場合は更新を行う。

   1. 計数計算結果DTOから以下の4つのサブDTOを取り出す
       - 一般与信状況計算結果（一般与信行リスト: 明細行＋合計行＋小計行を統一型Listで保持）
       - 本件後保全状況計算結果（引当状況行リスト: 担保明細行＋小計行＋合計行＋補正値行＋裸与信行を統一型Listで保持）
       - 科目明細当月増減額計算結果（市場性与信科目明細リスト＋簡易CF）
       - 保全率計算結果（保全率・金額単位・総合与信・総合信用、個別フィールド）

   1. 上記4つのサブDTOの内容を統合し、リポジトリに登録する

      リポジトリ呼出

      | 区分 | 値 |
      |---|---|
      | リポジトリ名 | 計数情報リポジトリ |
      | メソッド名 | 計数情報全項目保存 |
      | パラメータ1 | 案件番号 = 引数.案件番号 |
      | パラメータ2 | 補正区分 = 引数.補正区分 |
      | パラメータ3 | 一般与信状況計算結果 = 計数計算結果DTOから取り出した一般与信状況計算結果 |
      | パラメータ4 | 本件後保全状況計算結果 = 計数計算結果DTOから取り出した本件後保全状況計算結果 |
      | パラメータ5 | 科目明細当月増減額計算結果 = 計数計算結果DTOから取り出した科目明細当月増減額計算結果 |
      | パラメータ6 | 保全率計算結果 = 計数計算結果DTOから取り出した保全率計算結果 |
      | パラメータ7 | 店番 = 引数.店番 |
      | パラメータ8 | 取引先番号 = 引数.取引先番号 |
      | パラメータ9 | 禀査番号 = 引数.禀査番号 |
      | パラメータ10 | 基準日 = ステップ2で設定した基準日 |
      | 戻り値 | なし |

   1. 異常が発生した場合
      業務例外（YUSGS5019S-E）をスローする。

1. 稟議書（共通）データ更新
   案件番号をキーに、計数取得要否を「要」に、最終更新ユーザーIDを操作者ユーザーIDに更新する。

   リポジトリ呼出

   | 区分 | 値 |
   |---|---|
   | リポジトリ名 | 禀議共通リポジトリ |
   | メソッド名 | 計数取得要否更新(案件番号, ユーザーID) |
   | パラメータ1 | 案件番号 = 引数.案件番号 |
   | パラメータ2 | ユーザーID = コンテキストから取得した操作者ユーザーID |
   | 戻り値 | 更新件数 |

   1. 更新件数が0件の場合
      業務例外（YUSGS5019S-E）をスローする。
