## サービスクラス名(物理名)

RgV0501RinsashoCntInfoRegistFromMasterService

## サービスクラス名(論理名)

禀議・査定書（計数情報）マスタ再登録

## 処理詳細

1. インプット取得
   引数を取得し、サービスインプットDTOへマッピングする。

   データマッピング

   | 区分     | 値                |
   |---|---|
   | 参照シート名 | 【map仕様】サービスインプット |

1. 排他更新回数チェック
   楽観ロックによる排他更新回数チェックを行う。

   共通ライブラリ呼出

   | 区分     | 値 |
   |---|---|
   | 機能分類   | 排他制御ヘルパー |
   | 機能名称   | 排他チェック |
   | パラメータ1 | 排他キー = サービスインプットDTO.排他ロック情報.排他キー |
   | パラメータ2 | 更新回数 = サービスインプットDTO.排他ロック情報.排他回数 |
   | 戻り値    | 更新後の排他回数 |

   1. 排他更新回数チェックエラーの場合
      共通ライブラリから返却された例外をそのままクライアントに返却し、処理を終了する。

   1. 正常終了の場合
      戻り値として取得した更新後の排他回数をサービスアウトプットDTOに設定し、後続処理で使用する。

1. 補正区分を取得する
   案件番号をもとに補正区分を取得する。

   インナーサービス呼出

   | 区分 | 値 |
   |---|---|
   | 機能分類 | 稟議共通 |
   | 関数名 | 補正区分判定 |
   | パラメータ | 案件番号 = サービスインプットDTO.案件番号 |
   | 戻り値 | 補正区分 |

1. ホスト計数情報取得
   ホストから計数情報を取得し、後続処理で使用する元データを取得する。

   インナーサービス呼出

   | 区分 | 値 |
   |---|---|
   | 機能分類 | 計数共通機能 |
   | 関数名 | [ホスト計数情報取得](../インナー関数/サーバ関数仕様書_ホスト計数情報取得.md) |
   | パラメータ1 | 取引日 = サービスインプットDTO.取引日 |
   | パラメータ2 | 補正区分 = 補正区分 |
   | パラメータ3 | 取引先貸外店番 = サービスインプットDTO.取引先貸外店番 |
   | パラメータ4 | 取引先番号 = サービスインプットDTO.取引先番号 |
   | パラメータ5 | 案件番号 = サービスインプットDTO.案件番号 |
   | 戻り値 | ホスト計数情報DTO |

   1. ホスト計数情報取得の呼出結果が正常以外の場合
      インナーサービスから返却された例外をそのままクライアントに返却し、処理を終了する。

   1. ホスト計数情報取得が正常終了した場合
      戻り値として取得したホスト計数情報DTOを保持し、後続処理で使用する。

1. 顧客財務関連データ取得
   顧客財務関連のデータを取得する。

   インナーサービス呼出

   | 区分 | 値 |
   |---|---|
   | 機能分類 | 計数共通機能 |
   | 関数名 | [顧客財務関連データ取得](../インナー関数/サーバ関数仕様書_顧客財務関連データ取得.md) |
   | パラメータ1 | 店番 = サービスインプットDTO.店番 |
   | パラメータ2 | 取引先番号 = サービスインプットDTO.取引先番号 |
   | 戻り値 | 顧客財務関連データDTO |

   1. 顧客財務関連データ取得の呼出結果が正常以外の場合
      計数共通メソッドから返却された例外をそのままクライアントに返却し、処理を終了する。

   1. 顧客財務関連データ取得が正常終了した場合
      戻り値として取得した顧客財務関連データDTOを保持し、後続処理で使用する。

1. 計算用ベースデータ作成
   顧客財務関連データDTOとホスト計数情報DTOをもとに、項目ごとの採用ルールに従って計数ベースデータDTOを作成する。

   計数共通メソッド呼出

   | 区分 | 値 |
   |---|---|
   | 機能分類 | 計数共通機能 |
   | 関数名 | [計算用ベースデータ作成](../インナー関数/サーバ関数仕様書_計数ベースデータ作成.md) |
   | パラメータ1 | ホスト計数情報DTO = ホスト計数情報取得で取得したホスト計数情報DTO |
   | パラメータ2 | 顧客財務関連データDTO = 顧客財務関連データ取得で取得した顧客財務関連データDTO |
   | 戻り値 | 計数ベースデータDTO |

   1. 計算用ベースデータ作成の呼出結果が正常以外の場合
      計数共通メソッドから返却された例外をそのままクライアントに返却し、処理を終了する。

   1. 計算用ベースデータ作成が正常終了した場合
      戻り値として取得した計数ベースデータDTOを保持し、後続処理で使用する。

1. 計数計算
   計数ベースデータDTOを用いて、一般与信状況・本件後保全状況・科目明細当月増減額・保全率の全計算を一括実行する。

   インナーサービス呼出

   | 区分 | 値 |
   |---|---|
   | 機能分類 | 計数共通機能 |
   | 関数名 | [計数計算](../インナー関数/サーバ関数仕様書_計数計算.md) |
   | パラメータ | 計数ベースデータDTO |
   | 戻り値 | 計数計算結果DTO |

   1. 正常に計算できた場合
      戻り値として取得した計数計算結果DTOを保持し、後続処理で使用する。

1. 計数情報登録
   計算結果の各DTOと案件情報をもとに、計数案件番号取得・基準日設定・計数情報データ更新・計数取得要否更新を一括で行う。

   インナーサービス呼出

   | 区分 | 値 |
   |---|---|
   | 機能分類 | 計数共通機能 |
   | 関数名 | [計数情報登録](../インナー関数/サーバ関数仕様書_計数情報登録.md) |
   | パラメータ1 | 案件番号 = サービスインプットDTO.案件番号 |
   | パラメータ2 | 補正区分 = 補正区分 |
   | パラメータ3 | 店番 = サービスインプットDTO.店番 |
   | パラメータ4 | 取引先番号 = サービスインプットDTO.取引先番号 |
   | パラメータ5 | 禀査番号 = サービスインプットDTO.禀査番号 |
   | パラメータ6 | 計数計算結果DTO = 計数計算で取得した計算結果 |
   | 戻り値 | なし |

   1. 異常が発生した場合
      インナーサービスから返却された例外をそのままクライアントに返却し、処理を終了する。

1. サービスアウトプットDTO生成
   正常系または警告返却系の場合に、サービスアウトプットDTOを生成して返却する。
   例外終了の場合は、サービスアウトプットDTOは生成せず例外を送出する。

   データマッピング

   | 区分     | 値                  |
   |---|---|
   | 参照シート名 | 【マップ】サービスアウトプットDTO |
