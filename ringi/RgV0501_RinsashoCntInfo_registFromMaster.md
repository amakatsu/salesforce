## サービスクラス名(物理名)

RgV0501RinsashoCntInfoRegistFromMasterService

## サービスクラス名(論理名)

禀議・査定書（計数情報）マスタ再登録

## 処理詳細

1. インプット取得
   引数を取得し、サービスインプットDTOへマッピングする。

   データマッピング

   | 区分     | 値                |
   |---|---|
   | 参照シート名 | 【map仕様】サービスインプット |

1. 排他更新回数チェック
   楽観ロックによる排他更新回数チェックを行う。

   共通ライブラリ呼出

   | 区分     | 値 |
   |---|---|
   | 機能分類   | 排他制御ヘルパー |
   | 機能名称   | 排他チェック |
   | パラメータ1 | 排他キー = リクエストDTO.排他ロック情報（リクエスト）DTO.排他キー |
   | パラメータ2 | 更新回数 = リクエストDTO.排他ロック情報（リクエスト）DTO.排他回数 |
   | 戻り値    | 更新後の排他回数 |

   1. 排他更新回数チェックエラーの場合
      共通ライブラリから返却された例外をそのままクライアントに返却し、処理を終了する。

   1. 正常終了の場合
      戻り値として取得した更新後の排他回数をサービスアウトプットDTOに設定し、後続処理で使用する。

1. ホスト計数情報取得
   ホストから計数情報を取得し、後続処理で使用する元データを取得する。

   インナーサービス呼出

   | 区分 | 値 |
   |---|---|
   | 機能分類 | 計数共通機能 |
   | 関数名 | [ホスト計数情報取得](../インナー関数/サーバ関数仕様書_ホスト計数情報取得.md) |
   | パラメータ1 | 取引日 = サービスインプットDTO.取引日 |
   | パラメータ2 | 取引先貸外店番 = サービスインプットDTO.取引先貸外店番 |
   | パラメータ3 | 取引先番号 = サービスインプットDTO.取引先番号 |
   | パラメータ4 | 案件番号 = サービスインプットDTO.案件番号 |
   | 戻り値 | ホスト計数情報DTO |

   1. ホスト計数情報取得の呼出結果が正常以外の場合
      インナーサービスから返却された例外をそのままクライアントに返却し、処理を終了する。

   1. ホスト計数情報取得が正常終了した場合
      戻り値として取得したホスト計数情報DTOを保持し、後続処理で使用する。

1. 顧客財務関連データ取得
   顧客財務関連のデータを取得する。

   インナーサービス呼出

   | 区分 | 値 |
   |---|---|
   | 機能分類 | 計数共通機能 |
   | 関数名 | [顧客財務関連データ取得](../インナー関数/サーバ関数仕様書_顧客財務関連データ取得.md) |
   | パラメータ1 | 店番 = サービスインプットDTO.店番 |
   | パラメータ2 | 取引先番号 = サービスインプットDTO.取引先番号 |
   | 戻り値 | 顧客財務関連データDTO |

   1. 顧客財務関連データ取得の呼出結果が正常以外の場合
      計数共通メソッドから返却された例外をそのままクライアントに返却し、処理を終了する。

   1. 顧客財務関連データ取得が正常終了した場合
      戻り値として取得した顧客財務関連データDTOを保持し、後続処理で使用する。

1. 計算用ベースデータ作成
   顧客財務関連データDTOとホスト計数情報DTOをもとに、項目ごとの採用ルールに従って計数ベースデータDTOを作成する。

   計数共通メソッド呼出

   | 区分 | 値 |
   |---|---|
   | 機能分類 | 計数共通機能 |
   | 関数名 | [計算用ベースデータ作成](../インナー関数/サーバ関数仕様書_計数ベースデータ作成.md) |
   | パラメータ1 | ホスト計数情報DTO = ホスト計数情報取得で取得したホスト計数情報DTO |
   | パラメータ2 | 顧客財務関連データDTO = 顧客財務関連データ取得で取得した顧客財務関連データDTO |
   | 戻り値 | 計数ベースデータDTO |

   1. 計算用ベースデータ作成の呼出結果が正常以外の場合
      計数共通メソッドから返却された例外をそのままクライアントに返却し、処理を終了する。

   1. 計算用ベースデータ作成が正常終了した場合
      戻り値として取得した計数ベースデータDTOを保持し、後続処理で使用する。

      インナーサービス呼出

      | 区分 | 値 |
      |---|---|
      | 機能分類 | 計数共通機能 |
      | 関数名 | [一般与信状況計算](../インナー関数/サーバ関数仕様書_一般与信状況計算.md) |
      | パラメータ | 計数ベースデータDTO |
      | 戻り値 | 一般与信状況計算結果DTO |

   1. 本件後保全状況計算

      インナーサービス呼出

      | 区分 | 値 |
      |---|---|
      | 機能分類 | 計数共通機能 |
      | 関数名 | [本件後保全状況計算](../インナー関数/サーバ関数仕様書_本件後保全状況計算.md) |
      | パラメータ | 計数ベースデータDTO |
      | 戻り値 | 本件後保全状況計算結果DTO |

   1. 正常に計算できた場合
      戻り値として取得した一般与信状況計算結果DTOと本件後保全状況計算結果DTOを保持し、後続処理で使用する。

1. 科目明細当月増減額、保全率計算
   計数ベースデータDTOと一般与信・本件後保全状況計算結果を用いて、科目明細の当月増減額と保全率の計算を行う。

   1. 科目明細当月増減額計算

      インナーサービス呼出

      | 区分 | 値 |
      |---|---|
      | 機能分類 | 計数共通機能 |
      | 関数名 | [科目明細当月増減額計算](../インナー関数/サーバ関数仕様書_科目明細当月増減額計算.md) |
      | パラメータ | 計数ベースデータDTO |
      | 戻り値 | 科目明細計算結果DTO |

   1. 保全率計算

      インナーサービス呼出

      | 区分 | 値 |
      |---|---|

      | 関数名 | [保全率計算](../インナー関数/サーバ関数仕様書_保全率計算.md) |
      | パラメータ1 | 計数ベースデータDTO |
      | パラメータ2 | 一般与信状況計算結果DTO |
      | パラメータ3 | 本件後保全状況計算結果DTO |
      | 戻り値 | 保全率計算結果DTO |

   1. 正常に計算できた場合
      戻り値として取得した科目明細計算結果DTOと保全率計算結果DTOを保持し、後続処理で使用する。

9. 計数案件番号取得
   案件番号と変更前補正区分をキーに禀議共通情報を取得し、計数案件番号を取得する。

   DBアクセス

   | 区分     | 値                           |
   | ------ | --------------------------- |
   | リポジトリ名 | 禀議書(共通)_リポジトリ               |
   | メソッド名  | selectByPrimaryKeyAndDelFlg |
   | SQL条件  | 案件番号 = サービスインプットDTO.案件番号    |
   |        | AND 補正区分 = 変更前(0)           |
   |        | AND 削除フラグ = 0               |
   | 戻り値    | 禀議書(共通)エンティティ               |

   1. 取得レコード件数が0件の場合
      例外をスローする。

      例外スロー

      | 区分         | 値                            |
      | ---------- | ---------------------------- |
      | 例外クラス名     | ApplicationBusinessException |
      | エラーメッセージID | YUSGS5019S-E                 |

   2. 正常に禀議共通情報を取得できた場合
      取得した禀議共通情報エンティティから計数案件番号を取得し、後続処理で使用する。

1. 基準日設定
    取得した計数案件番号と変更前補正区分をキーに禀議共通情報を取得し、基準日元となる取引日を取得する。
    取引日が未設定の場合は営業日を取得し、基準日として採用する。

    DBアクセス

    | 区分     | 値                           |
    | ------ | --------------------------- |
    | リポジトリ名 | 禀議書(共通)_リポジトリ               |
    | メソッド名  | selectByPrimaryKeyAndDelFlg |
    | SQL条件  | 案件番号 = 計数案件番号取得で取得した計数案件番号  |
    |        | AND 補正区分 = 変更前(0)           |
    |        | AND 削除フラグ = 0               |
    | 戻り値    | 禀議書(共通)エンティティ               |

    1. 取得レコード件数が0件の場合
       例外をスローする。

       例外スロー

       | 区分         | 値                            |
       | ---------- | ---------------------------- |
       | 例外クラス名     | ApplicationBusinessException |
       | エラーメッセージID | YUSGS5019S-E                 |

    2. 正常に禀議共通情報を取得できた場合
       取得した禀議共通情報エンティティから取引日を取得する。

    3. 取得した取引日が未設定の場合
       当日営業日取得機能を呼び出し、当日営業日を取得する。

       共通ライブラリ呼出

       | 区分    | 値         |
       | ----- | --------- |
       | 機能分類  | カレンダー共通機能 |
       | 機能名称  | 当日営業日取得   |
       | パラメータ | なし        |
       | 戻り値   | 当日営業日     |

    4. 基準日を設定する
       取得した取引日、または当日営業日を基準日として設定する。

1. 計数情報データ更新
    最新計数情報、案件番号、入力店番、入力取引先番号、禀査番号、基準日をもとに計数情報を保存する。
    初回の計数情報マスタ登録時は追加を行い、それ以外は更新を行う。

    計数情報固有メソッド呼び出し

    | 区分     | 値                                                          |
    | ------ | ---------------------------------------------------------- |
    | 機能分類   | 計数DB固有機能                                                   |
    | 機能名称   | setKeisuAllData                                            |
    | パラメータ1 | 案件番号 = サービスインプットDTO.案件番号                                   |
    | パラメータ2 | 最新計数情報 = 一般与信状況、本件後保全状況欄計算および科目明細当月増減額、保全率計算の結果を反映した最終計数情報 |
    | パラメータ3 | 店番 = サービスインプットDTO.店番                                       |
    | パラメータ4 | 取引先番号 = サービスインプットDTO.取引先番号                                 |
    | パラメータ5 | 禀査番号 = サービスインプットDTO.禀査番号                                   |
    | パラメータ6 | 基準日 = 基準日設定で設定した基準日                                        |
    | 戻り値    | なし                                                         |

    処理内容は以下を参照
    docs\プログラム仕様書\01_サーバ仕様\005_計数照会\RgV0501_計数再取得\setKeisuAllData.md

    1. 異常が発生した場合
       業務例外をスローする。

       例外スロー

       | 区分         | 値                            |
       | ---------- | ---------------------------- |
       | 例外クラス名     | ApplicationBusinessException |
       | エラーメッセージID | YUSGS5019S-E                 |

1. 稟議書（共通）データ更新
    案件番号をキーに、計数取得要否を「要」、最終更新ユーザーIDを操作者ユーザーIDに更新する。

    DBアクセス

    | 区分                    | 値                        |
    | --------------------- | ------------------------ |
    | リポジトリ名                | 禀議書(共通)リポジトリ             |
    | メソッド（DynamicSQLの場合のみ） | updateKeisuYohi          |
    | SQL条件                 | 案件番号 = サービスインプットDTO.案件番号 |
    | 戻り値                   | 更新件数                     |

    1. 更新件数が0件の場合
       例外をスローする。

       例外スロー

       | 区分         | 値                            |
       | ---------- | ---------------------------- |
       | 例外クラス名     | ApplicationBusinessException |
       | エラーメッセージID | YUSGS5019S-E                 |

1. サービスアウトプットDTO生成
    正常系または警告返却系の場合に、サービスアウトプットDTOを生成して返却する。
    例外終了の場合は、サービスアウトプットDTOは生成せず例外を送出する。

    データマッピング

    | 区分     | 値                  |
    | ------ | ------------------ |
    | 参照シート名 | 【マップ】サービスアウトプットDTO |
