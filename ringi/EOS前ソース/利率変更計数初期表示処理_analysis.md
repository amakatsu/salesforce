# RLRRG004_B02_R01 分析レポート

> 利率変更（計数情報）画面 — 初期表示処理（559行）

## クラスの役割・責務

利率変更画面を開いた際の初期表示処理。DBから計数情報を取得し、ワークフローステータスに応じたボタン制御・照会/更新モード制御を行う。

## 継承・インタフェース

- 継承: `CraftsTransaction`
- 実装: `IRingiMsg`, `IRingiWF`, `IRingi`, `IRingiItem`, `IRingiItemRihenKeisu`

## 他クラスへの依存関係

| 依存先 | 用途 |
|--------|------|
| `RLRRG004_B02` (rihenkeisuCom) | 利率変更計数業務共通（ハッシュ間コピー、科目データ取得、出力設定） |
| `RLRRG004_B02_DB` (rihenkeisuDB) | 利率変更計数DB（全項目取得、ヘッダ情報取得、色変チェック） |
| `RLRRGCOM_RINGI` (ringiCom) | 禀議業務共通（共有情報初期化、null変換） |

| `RLRRGCOM_PROP_BASE` / `_FACT` / `_RES` | 項目属性管理（ボタン制御、色変設定） |
| `RLRCMCOM_CalendarWrapper` (Cal) | カレンダー（営業日取得） |

## DB操作の内容

| 操作 | メソッド | 内容 |

| READ | `rihenkeisuDB.getAllData()` | 利率変更計数情報の全項目取得（補正区分=1） |
| READ | `rihenkeisuDB.getKeisuHeaderInfo()` | ヘッダ情報の取得（データ未登録時） |
| READ | `rihenkeisuDB.compareItemData()` | 色変対象項目の比較取得 |

## ビジネスロジック概要

1. 操作者情報取得 → パラメータ設定
2. DBから利率変更計数情報を取得（補正区分=1）
3. WFステータス判定: 取消済/取下中/取下済/削除/否認/承認系 → 照会モード
4. **データ未登録時**:
   - ヘッダ情報のみ表示
   - ファイル作成・登録・直近計数照会ボタンを無効化
   - 照会モードまたは作成中以外 → 計数再取得も無効化
   - 基準日は営業日を設定
5. **データ登録済み時**:
   - 色変チェック（前回値との差分を色で表示）
   - 直近計数案件番号の有無でボタン制御
   - 照会/更新モード別のボタン制御
6. 禀査番号の設定（DB優先、なければ入力値）
7. ボタンプロテクト → 項目属性出力 → モードフラグ設定

## 設計上の特徴

- B01系とは異なるDB（`B02_DB`）と共通クラス（`B02`）を使用。利率変更に特化した画面初期化
- インタフェースも `IRingiItemRihenKeisu`（利率変更計数用）を使用し、B01系の `IRingiItemKeisu` とは別系統
- ボタン制御ロジックが5ファイル中最も複雑（データ有無 × WFステータス × 照会/更新モードの組み合わせ）
- コメントアウトされた旧ロジックが大量に残存しており、実質的なコード量は見た目より少ない
- 2003年STEP2対応で基準日・禀査番号の設定ロジックが追加、2004年にレベルアップ対応でボタン制御が改修
