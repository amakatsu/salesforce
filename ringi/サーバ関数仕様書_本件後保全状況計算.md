## 機能概要

計数ベースデータDTOと一般与信状況計算結果DTOをもとに、本件後保全状況（規定担保・規定外担保の各小計・合計・裸与信）の計算を行う。
計算結果は本件後保全状況計算結果DTOとして返却する。

現行ソース:
- `RLRRG004_B01.computeKokyakuShutoku()`（計数情報共通クラス.java L3294〜3373）
- `RLRRG004_B01.computeKokyaku()`（計数情報共通クラス.java L2366〜2888）

## 処理仕様

1. 引数を取得する
    計数ベースデータDTOおよび一般与信状況計算結果DTOから計算に必要な項目を取得する。

    1. 計数ベースデータDTOから以下の値を取得する
        - 本件後引当状況・規定値配列
        - 本件後引当状況・時価ベース配列
        - 本件後引当状況・規定値・合計配列
        - 本件後引当状況・時価ベース・合計配列
        - 規定・優良担保・商手(規定値)
        - 市場性与信_限度算入与信合計(本件後与信額)
        - 裸与信対象与信合計
        - 内HL信用不算入(本件後残高)

    1. 一般与信状況計算結果DTOから以下の値を取得する
        - 限度算入与信合計の本件後残高配列

1. 規定・優良・商手の初期計算を行う
    禀議取得時の初期計算として、規定・優良・商手の値を設定する。

    1. 以下の計算式で規定・優良・商手を求める

        ```
        規定・優良・商手 = 規定・優良・商手（規定値）[配列値] + 規定・優良担保・商手（引数）
        ```

    1. 計算結果が0より大きい場合、規定値・時価ベースの両方に設定する

    1. 計算結果が0以下の場合、規定値・時価ベースの両方を未設定とする

    1. 両方の入力値が未設定の場合、未設定を維持する

1. 裸与信の初期値を設定する
    禀議取得時は規定担保計が未設定のため、限度算入与信合計の値を初期値として設定する。

    1. 以下の値を設定する

        ```
        裸与信（規定値）= 市場性与信_限度算入与信合計（本件後与信額）
        裸与信（参考値）= 市場性与信_限度算入与信合計（本件後与信額）
        ```

1. 規定・優良小計を計算する
    規定値・時価ベースそれぞれについて、規定・優良小計を算出する。

    1. 以下の計算式で規定・優良小計を求める（規定値・時価ベースそれぞれ）

        ```
        規定・優良小計 = 預金 + 商手 + 担手 + 有証 + 協会保証 + 保証（除協会）
                     + 一般L/C + 手形保険 + 一括支払 + その他
        ```

    1. 全構成要素が未設定の場合は、小計も未設定とする

1. 規定・一般・不動産（抵）を計算する
    規定値・時価ベースそれぞれについて、不動産（抵）の合算を行う。

    1. 以下の計算式で規定・一般・不動産（抵）を求める

        ```
        規定・一般・不動産（抵）= 不動産（抵）+ 内HL(抵)
        ```

1. 規定・一般小計を計算する
    規定値・時価ベースそれぞれについて、規定・一般小計を算出する。

    1. 以下の計算式で規定・一般小計を求める

        ```
        規定・一般小計 = 有証 + 保証 + 不動産（抵）+ 不動産（根）+ D/F保証 + その他
        ```

    1. 全構成要素が未設定の場合は、小計も未設定とする

1. 規定・その他小計を計算する
    規定値・時価ベースそれぞれについて、規定・その他小計を算出する。

    1. 以下の計算式で規定・その他小計を求める

        ```
        規定・その他小計 = 有証 + 保証 + DHC・DC保証 + その他
        ```

    1. 全構成要素が未設定の場合は、小計も未設定とする

1. 規定担保合計を計算する
    各小計と規定担保補正値を用いて、規定担保合計を算出する。

    1. 以下の計算式で規定担保合計（規定値）を求める

        ```
        規定担保合計（規定値）= 規定・優良小計 + 規定・一般小計 + 規定・その他小計 − 規定担保補正値（規定値）
        ```

    1. 以下の計算式で規定担保合計（時価ベース）を求める

        ```
        規定担保合計（時価ベース）= 規定・優良小計 + 規定・一般小計 + 規定・その他小計 − 規定担保補正値（時価ベース）
        ```

    1. 計算結果が0以下の場合は0とする

    1. 全小計が未設定の場合は、規定担保合計も未設定とする

1. 規定外・優良小計を計算する
    規定値・時価ベースそれぞれについて、規定外・優良小計を算出する。

    1. 以下の計算式で規定外・優良小計を求める

        ```
        規定外・優良小計 = 預金 + 有証 + 保証 + その他
        ```

    1. 全構成要素が未設定の場合は、小計も未設定とする

1. 規定外・一般小計を計算する
    規定値・時価ベースそれぞれについて、規定外・一般小計を算出する。

    1. 以下の計算式で規定外・一般小計を求める

        ```
        規定外・一般小計 = 有証 + 保証 + 不動産（抵）+ 不動産（根）+ 入居保証金 + 債券 + その他
        ```

    1. 全構成要素が未設定の場合は、小計も未設定とする

1. 規定外担保合計を計算する
    規定値・時価ベースそれぞれについて、規定外担保合計を算出する。

    1. 以下の計算式で規定外担保合計を求める

        ```
        規定外担保合計 = 規定外・優良小計 + 規定外・一般小計 + 規定外・その他
        ```

    1. 全構成要素が未設定の場合は、合計も未設定とする

1. 裸与信を計算する
    限度算入与信合計・裸与信対象与信合計・規定担保合計・内HL信用不算入から裸与信を算出する。

    1. 以下の計算式で裸与信を求める

        ```
        裸与信 = 限度算入与信合計（本件後残高）[0]
               − 裸与信対象与信合計
               − 規定担保合計（規定値）
               − （内HL信用不算入（本件後残高）− 規定・一般担保・内HL(抵)（規定値））
        ```

    1. 裸与信がマイナス値の場合

        ```
        裸与信 = 0 + 裸与信対象与信合計
        ```

    1. 裸与信がプラス値の場合

        ```
        裸与信 = 裸与信 + 裸与信対象与信合計
        ```

    1. 全入力値が未設定の場合は、裸与信も未設定とする

1. 計算結果を返却する
    計算後の全配列を本件後保全状況計算結果DTOに設定して返却する。

    1. 本件後保全状況計算結果DTOに以下を設定して返却する
        - 再計算後の本件後引当状況・規定値配列（各小計を含む）
        - 再計算後の本件後引当状況・時価ベース配列（各小計を含む）
        - 再計算後の本件後引当状況・規定値・合計配列（規定担保合計、裸与信を含む）
        - 再計算後の本件後引当状況・時価ベース・合計配列（規定担保合計を含む）
