## 機能分類

計数共通機能

## 呼出し方法

CDI

## 機能名称

顧客財務関連データ取得

## モジュール名

KeisuCustomerDataGetService.java

## 関数名

getCustomerFinancialData

## クラス・アノテーション

なし

## メソッド・アノテーション

なし

## 機能概要

店番、取引先番号をもとに、顧客情報、財務情報、銀取計数、各種補正値等の顧客財務関連データを取得し、顧客財務関連データDTOとして返却する。

## 引数

| データ型 | 変数名(論理) | 補足 |
|---|---|---|
| String | 店番 |  |
| String | 取引先番号 |  |

## 戻り値

| データ型 | 戻り値(論理) | 補足 |
|---|---|---|
| 顧客財務関連データDTO | 顧客財務関連データDTO | 顧客財務関連データをまとめて保持する |

      `t_cim_gciflink_ibmcif gcf`, `t_cim_gt_keisu gtk`

      DBアクセス

      | 区分 | 値 |
      |---|---|
      | SQLID | rlrrg_o4183 |
      | メソッド名 | selectTop3ByDaiAttrNoAndToukou |
      | パラメータ1 | 代表属性番号 = 代表店番 + 代表CIF番号の連結値 |
      | パラメータ2 | 当行コード = `0005` |

      SQL概要
      最外SELECT句
      `bknm`, `jyoibk_znm`, `jyoibk_y1me`, `jyoibk_y2me`

      最外WHERE句
      `ROWNUM <= 3`

      内側SELECT句
      `gtb.bknm`, `SUM(gtk.keis60) AS jyoibk_znm`, `SUM(gtk.keis49) AS jyoibk_y1me`, `SUM(gtk.keis37) AS jyoibk_y2me`

      内側FROM句
      `t_cim_gciflink_ibmcif gcf`, `t_cim_gt_keisu gtk`, `t_cim_gt_bankcd gtb`

      内側WHERE句
      `gcf.dai_attr_no = RPAD(入力代表属性番号, 20, ' ')`
      `AND gcf.brno = gtk.brno`
      `AND gcf.triskno = gtk.triskno`
      `AND gtk.bkcd = gtb.bkcd`
      `AND gtk.bkcd != RPAD('0005', 5, ' ')`
      `AND gtk.out_kmk >= '01'`
      `AND gtk.out_kmk <= '50'`
      `AND gtk.del_flg = '0'`

      GROUP BY句
      `gtb.bknm`

      ORDER BY句
      `SUM(gtk.keis60) DESC`

      取得件数制限
      最外SELECTで `ROWNUM <= 3` を適用する

1. 表示月を決定する

   日付共通機能呼出で例外が発生した場合は、そのままスローする

   1) 表示月TOを決定する

      データ保有最終月が当月より2か月以内であるかを判定し、条件を満たす場合のみ表示月TOを設定する

      1) 当日営業日から1か月前の日付を取得する

         共通ライブラリ呼出

         | 区分 | 値 |
         |---|---|
         | 機能分類 | 日付共通機能 |
         | 機能名称 | 対象日付取得（月数指定） |
         | パラメータ1 | 基準日 = 当日営業日 |
         | パラメータ2 | 加減算月数 = -1 |
         | パラメータ3 | 存在しない日付時の後日日付採用有無 = false |
         | 戻り値 | 算出日付 |

         算出日付の年月部分（yyyyMM）とデータ保有最終月を比較する

         1) 算出日付の年月部分（yyyyMM）とデータ保有最終月が一致する場合
            表示月TOにデータ保有最終月を設定する

         1) 上記以外の場合
            当日営業日から2か月前の日付を取得する

            共通ライブラリ呼出

            | 区分 | 値 |
            |---|---|
            | 機能分類 | 日付共通機能 |
            | 機能名称 | 対象日付取得（月数指定） |
            | パラメータ1 | 基準日 = 当日営業日 |
            | パラメータ2 | 加減算月数 = -2 |
            | パラメータ3 | 存在しない日付時の後日日付採用有無 = false |
            | 戻り値 | 算出日付 |

            算出日付の年月部分（yyyyMM）とデータ保有最終月を比較する

            1) 算出日付の年月部分（yyyyMM）とデータ保有最終月が一致する場合
               表示月TOにデータ保有最終月を設定する

            1) 上記以外の場合
               表示月TOは設定しない

   1) 表示月FROMを決定する

      表示月TOが設定されている場合、表示月TOの5か月前を表示月FROMとして設定する

      1) 表示月TOが未設定の場合
         表示月FROMは設定しない

      1) 表示月TOが設定されている場合
         表示月TOに `'01'` を付加した日付を基準日として、5か月前の日付を取得する

         共通ライブラリ呼出

         | 区分 | 値 |
         |---|---|
         | 機能分類 | 日付共通機能 |
         | 機能名称 | 対象日付取得（月数指定） |
         | パラメータ1 | 基準日 = 表示月TO + `'01'` |
         | パラメータ2 | 加減算月数 = -5 |
         | パラメータ3 | 存在しない日付時の後日日付採用有無 = false |
         | 戻り値 | 算出日付 |

         算出日付の年月部分（yyyyMM）を表示月FROMに設定する

   1) 表示月前年TOを決定する

      表示月TOおよび表示月FROMが設定されている場合、表示月TOの12か月前を表示月前年TOとして設定する

      1) 表示月TOまたは表示月FROMが未設定の場合
         表示月前年TOは設定しない

      1) 表示月TOおよび表示月FROMが設定されている場合
         表示月TOに `'01'` を付加した日付を基準日として、12か月前の日付を取得する

         | パラメータ2 | 加減算月数 = -12 |
         | パラメータ3 | 存在しない日付時の後日日付採用有無 = false |
         | 戻り値 | 算出日付 |

         算出日付の年月部分（yyyyMM）を表示月前年TOに設定する

   1) 表示月前年FROMを決定する

      表示月前年TOが設定されている場合、表示月前年TOの5か月前を表示月前年FROMとして設定する
