## 機能概要

計数ベースデータDTOの一般与信関連項目に対して、補正値の適用・合計の積み上げ・当月増減額の計算を行う。
計算結果は一般与信状況計算結果DTOとして返却する。

現行ソース: `RLRRG004_B01.computeYosin()`（計数情報共通クラス.java L115〜566）

## 処理仕様

1. 引数を取得する
    計数ベースデータDTOから一般与信状況の計算に必要な各配列を取得する。

    1. 計数ベースデータDTOから以下の値を取得する
        - 一般与信の極度額配列
        - 一般与信の本件後残高配列
        - 補正値配列
        - 指定月末残高配列
        - 当月増減額配列
        - 実勢現在残高配列
        - 限度算入与信合計の極度額配列
        - 限度算入与信合計の本件後残高配列

1. 支払承諾合計を計算する
    月末残高・極度額・本件後残高・実勢現在残高の4指標について、支払承諾合計を計算する。

    1. 以下の計算式で4指標それぞれの支払承諾合計を求める

        ```
        支払承諾合計 = 支承・一般 + 支承・一般外為 + 代理貸付
        ```

    1. 全構成要素が未設定の場合は、支払承諾合計も未設定とする

1. 補正値を適用する
    補正対象の4項目に対して、極度額・本件後残高から補正値を減算する。

    1. 補正対象は以下の4項目である
        - 貸付金・商手合計
        - 内円貨
        - 外為与信合計
        - 支払承諾合計

    1. 以下の計算式で補正値を適用する

        ```
        極度額[i]     = 極度額[i] − 補正値[i]
        本件後残高[i] = 本件後残高[i] − 補正値[i]
        ```

    1. 計算結果が0以下の場合は0とする

    1. 極度額または本件後残高が未設定の場合は計算を行わず、未設定を維持する

1. 補正値の影響がある場合に合計を再計算する
    補正対象4項目のうち1つでも補正値が設定されている場合のみ、以下の合計項目を再計算する。

    1. オンバランス合計（極度額）を計算する

        ```
        オンバランス合計（極度額）= 貸付金・商手合計 + 外為与信合計 + 支払承諾合計 + 私募債 + 限度算入ローン合計
        ```

    1. オンバランス合計（本件後残高）を計算する

        ```
        オンバランス合計（本件後残高）= 貸付金・商手合計 + 外為与信合計 + 支払承諾合計 + 私募債 + 協保貸 + その他一般与信 + 限度算入ローン合計
        ```

        ※ 本件後残高のみ「協保貸」「その他一般与信」が加算対象

    1. 限度算入与信合計を計算する

        ```
        限度算入与信合計（極度額）   = オンバランス合計 + オフバランス合計
        限度算入与信合計（本件後残高）= オンバランス合計 + オフバランス合計
        ```

    1. 一般与信合計を計算する

        ```
        一般与信合計（極度額）   = 限度算入与信合計 + 限度不算入与信合計
        一般与信合計（本件後残高）= 限度算入与信合計 + 限度不算入与信合計
        ```

1. 特定与信合計を計算する
    特定与信合計の本件後残高を計算する。この計算では補正値を使用しない。

    1. 以下の計算式で特定与信合計を求める

        ```
        特定与信合計（本件後残高）= 特定与信1 + 特定与信2
        ```

1. 各行の当月増減額を計算する
    一般与信の全行について当月増減額を計算する。

    1. 以下の計算式で各行の当月増減額を求める

        ```
        極度額が0または未設定の場合:
            当月増減額 = 本件後残高 − 月末残高
        極度額が設定されている場合:
            当月増減額 = 本件後残高 − 極度額
        ```

    1. 本件後残高と月末残高（または極度額）の両方が未設定の場合は、当月増減額も未設定とする

    1. 以下の項目は計算対象外とし、当月増減額の計算を行わない
        - 限度不算入与信合計〜L/G
        - 内円貨
        - 協保貸
        - その他一般与信
        - 特定与信合計
        - 特定与信1

1. 合計項目の増減額を集計する
    各合計項目の当月増減額を構成要素の増減額から算出する。

    1. 貸付金・商手合計の増減額を計算する

        ```
        貸付金・商手合計（増減額）= 明細1 + 明細2 + ... + 明細12
        ```

    1. 外為与信合計の増減額を計算する

        ```
        外為与信合計（増減額）= 輸出小計 + 輸出貸出 + 輸入小計 + 輸入貸出 + 故障指定L/C + ユーザンスシフト外貨
        ```

    1. 支払承諾合計の増減額を計算する

        ```
        支払承諾合計（増減額）= 支承・一般 + 支承・一般外為 + 代理貸付
        ```

    1. オンバランス合計の増減額を計算する

        ```
        オンバランス合計（増減額）= 貸付金・商手合計 + 外為与信合計 + 支払承諾合計 + 私募債 + 限度算入ローン合計
        ```

    1. 限度算入与信合計の増減額を計算する

        ```
        限度算入与信合計（増減額）= オンバランス合計 + オフバランス合計
        ```

    1. 一般与信合計の増減額を設定する

        ```
        一般与信合計（増減額）= 限度算入与信合計（増減額の値をそのまま設定）
        ```

    1. 各合計項目について、全構成要素が未設定の場合は合計も未設定とする

1. 計算結果を返却する
    計算後の全配列を一般与信状況計算結果DTOに設定して返却する。

    1. 一般与信状況計算結果DTOに以下を設定して返却する
        - 補正適用後の極度額配列
        - 補正適用後の本件後残高配列
        - 再計算後の指定月末残高配列
        - 再計算後の当月増減額配列
        - 再計算後の実勢現在残高配列
        - 当月増減額合計配列
        - 再計算後の限度算入与信合計の極度額配列
        - 再計算後の限度算入与信合計の本件後残高配列
