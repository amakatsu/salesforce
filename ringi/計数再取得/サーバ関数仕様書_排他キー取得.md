## 機能分類

稟議共通機能

## 呼出し方法

CDI

## 機能名称

排他キー取得

## モジュール名

計数排他キー取得サービス

## クラス名

`KaisuHaitaKeyService`

## 関数一覧

| 関数名 | 用途 |
|---|---|
| `getAnkenHaitaKey` | 案件番号をもとに、禀議書単位の排他キーと初期更新回数を取得する |
| `getCifHaitaKey` | 店番＋取引先番号をもとに、顧客CIF単位の排他キーと初期更新回数を取得する |

## クラス・アノテーション

なし

## メソッド・アノテーション

なし

## 機能概要

計数情報画面の排他制御に使用する排他キーと初期更新回数を取得する。

排他制御の単位は、呼び出し側が利用する関数により明示する。

- 案件番号をもとに排他制御を行う場合は、`getAnkenHaitaKey` を使用する。
- 店番＋取引先番号をもとに排他制御を行う場合は、`getCifHaitaKey` を使用する。

本機能では、案件番号の有無による排他キー種別の自動判定は行わない。  
呼び出し側は、排他制御の対象に応じて使用する関数を選択する。

## 戻り値DTO

### DTO名

`HaitaKeyInfoDto`

### DTO構造

| 項目名 | 型 | 補足 |
|---|---|---|
| 排他キー | String | 案件番号、またはCIFキー |
| 更新回数 | Integer | 対象テーブルから取得した更新回数。未登録の場合は0 |

# 1. 案件排他キー取得

## 関数名

`getAnkenHaitaKey`

## メソッドシグニチャ

```java
HaitaKeyInfoDto getAnkenHaitaKey(String ankenNo)
````

## 機能概要

案件番号をキーとして、禀議書（共通）テーブルから更新回数を取得する。
取得した案件番号を排他キーとして設定し、更新回数とあわせて排他キー情報DTOとして返却する。

本関数は、禀議書単位の排他制御を行う場合に使用する。

## 引数

| データ型   | 変数名       | 変数名(論理) | 補足                      |
| ------ | --------- | ------- | ----------------------- |
| String | `ankenNo` | 案件番号    | 禀議書（共通）テーブルの検索キーとして使用する |

## 戻り値

| データ型              | 戻り値(論理) | 補足               |
| ----------------- | ------- | ---------------- |
| `HaitaKeyInfoDto` | 排他キー情報  | 排他キーと初期更新回数を保持する |

## 処理仕様

1. 入力チェックを行う

   1. 案件番号が未設定の場合
      業務例外をスローする。
      ※エラーコードはTBD。

2. 排他キーを設定する

   排他キー = 引数.案件番号

3. 更新回数を取得する

   案件番号をキーに、禀議書（共通）テーブルから更新回数を取得する。

   リポジトリ呼出

   | 区分        | 値                         |
   | --------- | ------------------------- |
   | リポジトリ名    | 禀議共通リポジトリ                 |
   | リポジトリクラス名 | `RingiKyotsuRepository`   |
   | メソッド名     | `getKoshinKaisuByAnkenNo` |
   | パラメータ     | 案件番号 = 引数.`ankenNo`       |
   | 戻り値       | 更新回数                      |

4. 取得レコード件数が0件の場合

   業務例外（YUSGS5019S-E）をスローする。

5. 正常に取得できた場合

   取得した更新回数を保持する。

6. 排他キー情報DTOを返却する

   `HaitaKeyInfoDto` に以下を設定して返却する。

   | 項目   | 設定値                   |
   | ---- | --------------------- |
   | 排他キー | 引数.案件番号               |
   | 更新回数 | 禀議書（共通）テーブルから取得した更新回数 |

## 呼び出し例

```java
HaitaKeyInfoDto haitaKeyInfo =
        kaisuHaitaKeyService.getAnkenHaitaKey(ankenNo);
```

# 2. CIF排他キー取得

## 関数名

`getCifHaitaKey`

## メソッドシグニチャ

```java
HaitaKeyInfoDto getCifHaitaKey(String tenban, String torihikisakiNo)
```

## 機能概要

店番および取引先番号をキーとして、計数情報テーブルから更新回数を取得する。
店番と取引先番号を連結した値をCIF排他キーとして設定し、更新回数とあわせて排他キー情報DTOとして返却する。

本関数は、顧客CIF単位の排他制御を行う場合に使用する。

## 引数

| データ型   | 変数名              | 変数名(論理) | 補足                   |
| ------ | ---------------- | ------- | -------------------- |
| String | `tenban`         | 店番      | 計数情報テーブルの検索キーとして使用する |
| String | `torihikisakiNo` | 取引先番号   | 計数情報テーブルの検索キーとして使用する |

## 戻り値

| データ型              | 戻り値(論理) | 補足               |
| ----------------- | ------- | ---------------- |
| `HaitaKeyInfoDto` | 排他キー情報  | 排他キーと初期更新回数を保持する |

## 処理仕様

1. 入力チェックを行う

   1. 店番が未設定の場合
      業務例外をスローする。
      ※エラーコードはTBD。

   2. 取引先番号が未設定の場合
      業務例外をスローする。
      ※エラーコードはTBD。

2. 排他キーを設定する

   排他キー = 引数.店番 ＋ 引数.取引先番号

3. 更新回数を取得する

   店番および取引先番号をキーに、計数情報テーブルから更新回数を取得する。

   リポジトリ呼出

   | 区分        | 値                           |
   | --------- | --------------------------- |
   | リポジトリ名    | 計数情報リポジトリ                   |
   | リポジトリクラス名 | `KaisuJohoRepository`       |
   | メソッド名     | `getKoshinKaisuByCif`       |
   | パラメータ1    | 店番 = 引数.`tenban`            |
   | パラメータ2    | 取引先番号 = 引数.`torihikisakiNo` |
   | 戻り値       | 更新回数                        |

4. 取得レコード件数が0件の場合

   計数情報が未登録、すなわち初回登録であるため、更新回数を0として設定する。

5. 正常に取得できた場合

   計数情報テーブルから取得した更新回数を保持する。

6. 排他キー情報DTOを返却する

   `HaitaKeyInfoDto` に以下を設定して返却する。

   | 項目   | 設定値                     |
   | ---- | ----------------------- |
   | 排他キー | 引数.店番 ＋ 引数.取引先番号        |
   | 更新回数 | 計数情報テーブルから取得した更新回数、または0 |
