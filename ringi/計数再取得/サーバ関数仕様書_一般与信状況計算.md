## 機能概要

計数ベースデータDTOの一般与信行リストに対して、補正値の適用・合計の積み上げ・当月増減額の計算を行う。
計算結果は一般与信状況計算結果DTOとして返却する。
一般与信の全行（明細行・小計行・合計行）は `List<IppanYoshinRow>` で統一管理され、行キーで識別する。

現行ソース: `RLRRG004_B01.computeYosin()`（計数情報共通クラス.java L115〜566）

## 処理仕様

1. 引数を取得する
    計数ベースデータDTOから一般与信行リストを取得する。

    1. 計数ベースデータDTOから一般与信行リストを取得する
        リストには明細行・小計行・合計行の全行が含まれる。各行は行キーで識別する。

1. 支払承諾合計を計算する
    一般与信行リストから行キー=支承・一般/支承・一般外為/代理貸付の3行を取得し、月末残高・極度額・本件後残高・実勢現在残高の4指標について支払承諾合計を計算する。

    1. 一般与信行リストから以下の3行を取得する
        - 行キー=支承・一般
        - 行キー=支承・一般外為
        - 行キー=代理貸付

    1. 以下の計算式で4指標それぞれの支払承諾合計を求める

        ```
        支払承諾合計 = 支承・一般 + 支承・一般外為 + 代理貸付
        ```

    1. 3行すべてが未設定の場合は、支払承諾合計行も未設定とする

    1. 計算結果を一般与信行リストの行キー=支払承諾合計の行に設定する

1. 補正値を適用する
    補正対象の4行に対して、極度額・本件後残高から各行の補正値を減算する。

    1. 補正対象は以下の4行である
        - 行キー=貸付金・商手合計
        - 行キー=内円貨
        - 行キー=外為与信合計
        - 行キー=支払承諾合計

    1. 各補正対象行について、その行の補正値を極度額・本件後残高から減算する

        ```
        対象行.極度額 = 対象行.極度額 − 対象行.補正値
        対象行.本件後残高 = 対象行.本件後残高 − 対象行.補正値
        ```

    1. 計算結果が0以下の場合は0とする

    1. 極度額または本件後残高が未設定の場合は計算を行わず、未設定を維持する

1. 補正値の影響がある場合に合計を再計算する
    補正対象の貸付金・商手合計、外為与信合計、支払承諾合計の3行のうち1つでも補正値が設定されている場合のみ、以下の合計行を再計算する（内円貨は合計再計算のトリガーに含まない）。

    1. 行キー=オンバランス合計の極度額を計算する

        ```
        オンバランス合計（極度額）= 貸付金・商手合計行.極度額 + 外為与信合計行.極度額 + 支払承諾合計行.極度額 + 私募債行.極度額 + 限度算入ローン合計行.極度額
        ```

    1. 行キー=オンバランス合計の本件後残高を計算する

        ```
        オンバランス合計（本件後残高）= 貸付金・商手合計行.本件後残高 + 外為与信合計行.本件後残高 + 支払承諾合計行.本件後残高 + 私募債行.本件後残高 + 協保貸行.本件後残高 + その他一般与信行.本件後残高 + 限度算入ローン合計行.本件後残高
        ```

        ※ 本件後残高のみ「協保貸」「その他一般与信」が加算対象

    1. 行キー=限度算入与信合計を計算する

        ```
        限度算入与信合計（極度額）   = オンバランス合計行.極度額 + オフバランス合計行.極度額
        限度算入与信合計（本件後残高）= オンバランス合計行.本件後残高 + オフバランス合計行.本件後残高
        ```

    1. 行キー=一般与信合計を計算する

        ```
        一般与信合計（極度額）   = 限度算入与信合計行.極度額 + 限度不算入与信合計行.極度額
        一般与信合計（本件後残高）= 限度算入与信合計行.本件後残高 + 限度不算入与信合計行.本件後残高
        ```

1. 特定与信合計を計算する
    行キー=特定与信合計の本件後残高を計算する。この計算では補正値を使用しない。

    1. 以下の計算式で行キー=特定与信合計の本件後残高を求める

        ```
        特定与信合計行.本件後残高 = 特定与信1行.本件後残高 + 特定与信2行.本件後残高
        ```

1. 各明細行の当月増減額を計算する
    一般与信行リストの明細行（行種別=明細）および一部の小計行について当月増減額を計算する。

    1. 以下の計算式で各行の当月増減額を求める

        ```
        対象行.極度額が0または未設定の場合:
            対象行.当月増減額 = 対象行.本件後残高 − 対象行.月末残高
        対象行.極度額が設定されている場合:
            対象行.当月増減額 = 対象行.本件後残高 − 対象行.極度額
        ```

    1. 本件後残高と月末残高（または極度額）の両方が未設定の場合は、当月増減額も未設定とする

    1. 以下の行キーの行は当月増減額の計算を行わない
        - 行キー=限度不算入与信合計、年金転貸、指定L/C小切手、L/G
        - 行キー=内円貨
        - 行キー=協保貸
        - 行キー=その他一般与信
        - 行キー=特定与信合計、特定与信1

1. 合計行の増減額を集計する
    各合計行の当月増減額を構成要素行の増減額から算出する。

    1. 行キー=貸付金・商手合計の増減額を計算する
        行キー=貸付金明細1〜12の全12行の当月増減額を合算する。

    1. 行キー=外為与信合計の増減額を計算する
        行キー=輸出小計/貸出（輸出）/輸入小計/貸出（輸入）/故障指定L/C/ユーザンスシフト外貨の6行の当月増減額を合算する。

    1. 行キー=支払承諾合計の増減額を計算する
        行キー=支承・一般/支承・一般外為/代理貸付の3行の当月増減額を合算する。

    1. 行キー=オンバランス合計の増減額を計算する

        ```
        オンバランス合計行.当月増減額 = 貸付金・商手合計行.当月増減額 + 外為与信合計行.当月増減額 + 支払承諾合計行.当月増減額 + 私募債行.当月増減額 + 限度算入ローン合計行.当月増減額
        ```

    1. 行キー=限度算入与信合計の増減額を計算する

        ```
        限度算入与信合計行.当月増減額 = オンバランス合計行.当月増減額 + オフバランス合計行.当月増減額
        ```

    1. 行キー=一般与信合計の増減額を設定する

        ```
        一般与信合計行.当月増減額 = 限度算入与信合計行.当月増減額（値をそのまま設定）
        ```

    1. 各合計行について、全構成要素行が未設定の場合は合計行も未設定とする

1. 計算結果を返却する
    新しい一般与信状況計算結果DTOを生成し、計算結果を設定して返却する。引数の計数ベースデータDTOは変更しない。

    1. 新しい一般与信状況計算結果DTOを生成する

    1. 一般与信行リストを新規作成し、入力の全行をコピーしたうえで、補正適用・合計再計算・当月増減額再計算後の値を反映する。行キー体系は入力と同一とする
