## 機能分類

計数共通機能

## 呼出し方法

CDI

## 機能名称

ホスト計数情報取得

## モジュール名

KeisuHostDataGetService.java

## 関数名

getHostKeisuInfo

## クラス・アノテーション

なし

## メソッド・アノテーション

なし

## 機能概要

リクエストスコープから操作者情報を取得し、案件番号をもとに補正区分と取引日を決定する。
決定した取引日、操作者情報、引数で指定された案件情報をもとにホストから計数情報を取得する。
取得結果が正常の場合はホスト計数情報DTOを返却し、正常以外の場合は警告情報を保持した例外を送出する。

|---|---|---|
| Date | 取引日 | 未設定の場合は当日営業日を採用する |
| String | 補正区分 |  |
| String | 取引先貸外店番 |  |
| String | 取引先番号 |  |
| String | 案件番号 |  |

## 戻り値

| データ型 | 戻り値(論理) | 補足 |
|---|---|---|
| ホスト計数情報DTO | ホスト計数情報DTO | 正常終了時に返却する |

## 処理仕様

1. 取引日を決定する
    ホスト計数取得に使用する取引日を決定する。
    引数.取引日が設定されている場合はその値を使用する。
    未設定の場合は、補正区分と案件番号をキーに禀議書から取引日を取得する。
    禀議書の取引日も未設定の場合は当日営業日を採用する。

    1. 引数.取引日が設定されている場合
        引数の値をそのまま取引日として設定する。

    1. 引数.取引日が未設定の場合
        1. 禀議書から取引日を取得する。

        リポジトリ呼出

        | 区分 | 値 |
        |---|---|
        | リポジトリ名 | 禀議書リポジトリ |
        | メソッド名 | 案件番号と補正区分で禀議書取得(案件番号, 補正区分) |
        | パラメータ1 | 案件番号 = 引数.案件番号 |
        | パラメータ2 | 補正区分 = 引数.補正区分 |
        | 戻り値 | 禀議書エンティティ |

        1. 禀議書の取引日も未設定の場合
            当日営業日取得機能を呼び出し、その戻り値を取引日として採用する。

            共通ライブラリ呼出

            | 区分 | 値 |
            |---|---|
            | 機能分類 | カレンダー共通機能 |
            | 機能名称 | 当日営業日取得 |
            | パラメータ | なし |
            | 戻り値 | 当日営業日 |

    1. 取引日を設定する
        上記で決定した値を取引日として設定する。

1. ホストから計数情報を取得する
    操作者情報、決定した取引日、引数で指定された案件情報をもとにホストから計数情報を取得する。

    計数共通メソッド呼出

    | 区分 | 値 |
    |---|---|
    | 機能分類 | 禀議共通機能 |
    | 機能名称 | 計数情報(利変以外)取得処理 |
    | パラメータ1 | ユーザーID = リクエストスコープから取得したユーザーID |
    | パラメータ2 | 部店コード = リクエストスコープから取得した部店コード |
    | パラメータ3 | 課・Grコード = リクエストスコープから取得した課・Grコード |
    | パラメータ4 | 役職順コード = リクエストスコープから取得した役職順コード |
    | パラメータ5 | 取引先貸外店番 = 引数.取引先貸外店番 |
    | パラメータ6 | 取引先番号 = 引数.取引先番号 |
    | パラメータ7 | 案件番号 = 引数.案件番号 |
    | パラメータ8 | 取引日 = 本処理で設定した取引日 |
    | 戻り値 | ホスト計数情報DTO |

1. 取得結果を返却する
    ホスト計数情報取得結果に応じて、戻り値の返却または警告例外の送出を行う。

    1. 計数共通メソッド呼出結果が正常以外の場合
        共通ライブラリから通知された警告情報を保持した例外を送出する。

    1. 計数共通メソッド呼出が正常終了した場合
        取得したホスト計数情報DTOを戻り値に設定して返却する。
