## 機能概要

一般与信と市場性与信の金額単位を統一したうえで、限度算入一般与信・限度算入市場性与信・規定担保合計の各金額を単位変換し、保全率（%）・総合与信・総合信用を算出する。

現行メソッド: `computeHozen`（計数情報共通クラス.java L5426-5738）

## 処理仕様

1. 金額単位を決定する
    一般与信タブと市場性与信タブの金額単位を比較し、保全率表示に使用する金額単位を決定する。

    1. 金額単位文言を金額単位コードに変換する

        | 金額単位文言 | 金額単位コード |
        |---|---|
        | 千円 | 1 |
        | 百万円 | 2 |
        | 億円 | 3 |
        | 上記以外 | 空文字 |

    1. 一般与信の金額単位コードと市場性与信の金額単位コードを比較する
        大きい方のコードを「表示用単位コード」、小さい方のコードを「計算用単位コード」として保持する。

    1. 保全率・金額単位を設定する
        表示用単位コードに対応する金額単位文言を保全率・金額単位に設定する。

1. 限度算入一般与信を算出する
    一般与信1_限度算入与信合計（本件後残高）を表示用単位に変換する。

    1. 本件後残高が未設定（nullまたは空文字）の場合
        結果を空文字に設定する。

    1. 本件後残高が「0」の場合
        結果を「0」に設定する。

    1. 上記以外の場合
        金額単位変換を行う。

        共通ライブラリ呼出

        | 区分 | 値 |
        |---|---|
        | 機能分類 | 計数共通機能 |
        | 機能名称 | 金額単位変換 |
        | パラメータ1 | 金額 = 一般与信1_限度算入与信合計（本件後残高） |
        | パラメータ2 | 変換元単位 = 一般与信の金額単位コード |
        | パラメータ3 | 変換先単位 = 表示用単位コード |
        | パラメータ4 | 端数処理 = 切り上げ |
        | 戻り値 | 単位変換後の金額 |

1. 限度算入市場性与信を算出する
    市場性与信1_限度算入与信合計（本件後与信額）を表示用単位に変換する。

    1. 本件後与信額が未設定（nullまたは空文字）の場合
        結果を空文字に設定する。

    1. 本件後与信額が「0」の場合
        結果を「0」に設定する。

    1. 上記以外の場合
        金額単位変換を行う。

        共通ライブラリ呼出

        | 区分 | 値 |
        |---|---|
        | 機能分類 | 計数共通機能 |
        | 機能名称 | 金額単位変換 |
        | パラメータ1 | 金額 = 市場性与信1_限度算入与信合計（本件後与信額） |
        | パラメータ2 | 変換元単位 = 市場性与信の金額単位コード |
        | パラメータ3 | 変換先単位 = 表示用単位コード |
        | パラメータ4 | 端数処理 = 切り上げ |
        | 戻り値 | 単位変換後の金額 |

1. 規定担保合計を算出する
    一般与信1_規定担保合計（規定値）を表示用単位に変換する。

    1. 規定担保合計が未設定（nullまたは空文字）の場合
        結果を空文字に設定する。

    1. 規定担保合計が「0」の場合
        結果を「0」に設定する。

    1. 上記以外の場合
        金額単位変換を行う。端数処理は**切り捨て**（保守的に低く見積もる）。

        共通ライブラリ呼出

        | 区分 | 値 |
        |---|---|
        | 機能分類 | 計数共通機能 |
        | 機能名称 | 金額単位変換 |
        | パラメータ1 | 金額 = 一般与信1_規定担保合計（規定値） |
        | パラメータ2 | 変換元単位 = 一般与信の金額単位コード |
        | パラメータ3 | 変換先単位 = 表示用単位コード |
        | パラメータ4 | 端数処理 = 切り捨て |
        | 戻り値 | 単位変換後の金額 |

1. 保全率を算出する
    限度算入一般与信と限度算入市場性与信の合計に対する規定担保合計の割合を保全率として算出する。

    1. 限度算入一般与信と限度算入市場性与信がともに空文字の場合
        保全率を空文字に設定する。

    1. 規定担保合計が空文字の場合
        保全率を「0.00」に設定する。

    1. 上記以外の場合
        金額単位が一般与信と市場性与信で異なる場合、計算用単位コード（小さい方）に揃えて計算する。

        1. 一般与信の金額単位コードと市場性与信の金額単位コードが異なる場合
            各金額を計算用単位コードに変換する。
            - 限度算入一般与信: 切り上げで変換
            - 限度算入市場性与信: 切り上げで変換
            - 規定担保合計: 切り捨てで変換

        1. 保全率を計算する

            ```
            保全率 = (規定担保合計 × 100.0) ÷ (限度算入一般与信 + 限度算入市場性与信)
            ```

            - 限度算入一般与信 + 限度算入市場性与信が0の場合、保全率を空文字に設定する
            - 小数点第3位で切り捨て（RoundingMode.DOWN, scale=2）
            - 結果が999.99を超える場合は「999.99」に設定する

1. 総合与信を算出する
    限度算入一般与信と限度算入市場性与信の合計金額を表示用単位で算出する。

    1. 限度算入一般与信と限度算入市場性与信がともに空文字の場合
        総合与信を空文字に設定する。

    1. 上記以外の場合
        計算用単位コード（小さい方）で一般与信と市場性与信を加算し、表示用単位コード（大きい方）に切り上げで変換する。

        ```
        総合与信 = 限度算入一般与信 + 限度算入市場性与信
        ```

        共通ライブラリ呼出

        | 区分 | 値 |
        |---|---|
        | 機能分類 | 計数共通機能 |
        | 機能名称 | 金額単位変換 |
        | パラメータ1 | 金額 = 総合与信（計算用単位での合計値） |
        | パラメータ2 | 変換元単位 = 計算用単位コード |
        | パラメータ3 | 変換先単位 = 表示用単位コード |
        | パラメータ4 | 端数処理 = 切り上げ |
        | 戻り値 | 単位変換後の総合与信 |

1. 総合信用を算出する
    総合与信から規定担保合計を差し引いた金額を表示用単位で算出する。

    1. 限度算入一般与信と限度算入市場性与信がともに空文字の場合
        総合信用を空文字に設定する。

    1. 上記以外の場合
        計算用単位コード（小さい方）で計算する。

        ```
        総合信用 = (限度算入一般与信 + 限度算入市場性与信) − 規定担保合計
        ```

        1. 総合信用が0未満の場合
            総合信用を「0」に設定する。

        1. 総合信用が0以上の場合
            表示用単位コードに変換する。

            共通ライブラリ呼出

            | 区分 | 値 |
            |---|---|
            | 機能分類 | 計数共通機能 |
            | 機能名称 | 金額単位変換 |
            | パラメータ1 | 金額 = 総合信用（計算用単位での値） |
            | パラメータ2 | 変換元単位 = 計算用単位コード |
            | パラメータ3 | 変換先単位 = 表示用単位コード |
            | パラメータ4 | 端数処理 = 切り上げ |
            | 戻り値 | 単位変換後の総合信用 |

1. 計算結果を返却する
    保全率計算結果DTOに全計算結果を設定して返却する。

    1. 以下の項目を保全率計算結果DTOに設定する
        - 保全率・金額単位
        - 保全率・限度算入一般与信
        - 保全率・限度算入市場性与信
        - 保全率・規定担保合計
        - 保全率・保全率
        - 保全率・総合与信
        - 保全率・総合信用
