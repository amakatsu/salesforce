# Internal Documentation Hub

Use this space for team-only checklists, status, and release artifacts.

## What's inside
| File | Purpose |
| --- | --- |
| `STATUS.md` | Detailed implementation status (done, pending, risks) |
| `SUMMARY.md` | High-level project summary (95% complete, next steps) |
| `CHANGELOG.md` | Source-of-truth change log across releases |
| `RELEASE_NOTES_v1.0.0.md` | Notes for the current packaged release |
| `WINDOWS_BUILD.md` | Steps for generating the Windows installer (still pending) |
| `issues.md` | Backlog / task tracking list |

When sharing externally, stick to `docs/external/README.md` and the files alongside it. Everything in `docs/internal/` is meant for the core dev team.
