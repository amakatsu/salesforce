# ドメインチェッカー改良 設計仕様書

## 概要

画面項目定義とテーブル定義の2ファイルをアップロードし、
既存のドメイン一覧とのマッチングを行い、一致率・候補を提案するツール。

---

## 1. インプット

### 1-1. 画面項目定義

- **シート名**: 画面項目定義
- **ヘッダー検索方式**: 部分一致（含む）
- **対象列**:

| 列名 | 用途 |
|------|------|
| 項目名称 | マッチングキー |
| 型 | 大分類判定 |
| テキストタイプ | ドメインデータ型の絞り込み |
| 最小桁 | 桁数照合 |
| 最大桁 | 桁数照合 |
| 最大バイト数 | バイト長照合 |
| 最小値 | 数値範囲照合 |
| 最大値 | 数値範囲照合 |
| 外部コード | 外部コード照合 |

- **対象外判定**: 項目名称のみあり、テキストタイプ〜外部コードが全て空 → 「対象外」

### 1-2. テーブル定義

- **シート名**: テーブル定義
- **ヘッダー検索方式**: 部分一致（含む）
- **対象列**:

| 列名 | 用途 |
|------|------|
| 論理項目名 | マッチングキー |
| データ型 | 大分類判定 |
| Length | 桁数照合 |
| 全体数値 | 整数部照合 |
| 少数桁 | 小数部照合 |

- **対象外判定**: 論理項目名のみあり、データ型〜少数桁が全て空 → 「対象外」
- **テキストタイプなし**: テーブル定義にはテキストタイプがないため、大分類＋桁数のみで判定

### 1-3. ドメイン一覧（既存・アップロード不要）

- **ヘッダー検索方式**: 部分一致（含む）
- **対象列**:

| 列名 | 用途 |
|------|------|
| ドメイン名 | マッチング結果として出力 |
| データ型 | 大分類・詳細型判定 |
| 最小文字数 | 文字列桁数照合 |
| 最大文字数 | 文字列桁数照合 |

| 小数部桁数 | 数値桁数照合 |
| 書式（正規表現） | 参考情報 |
| 参照外部コード | 外部コード照合 |

### 1-4. ドメイン一覧のデータ型一覧

### 重複排除の基準

- **項目名（数字除去後）＋桁数**が完全一致していたら重複とみなし1つに集約

### VLOOKUPの仕組み

- 抽出シートのキー（項目名等）で重複排除シートを参照し、一致ドメイン名を取得

## 3. マッチングロジック

### 3-1. 全体フロー

```
項目
 │
 ├─ 対象外判定
 │   → 属性列が全て空なら「対象外」で終了
 │
 ├─ 特殊パターン判定
 │   ├─ フラグ: 項目名に「フラグ」含む + boolean/0,1
 │   │   → 「以下から選択: 0/1, 0/9, null/1, スペース/1」と記載
 │   ├─ コメント: 項目名に「コメント」含む
 │   │   → 「改行あり/なしを確認して選択してください」と記載
 │   ├─ 補記: 項目名に「補記」含む
 │   │   → コメントと同様
 │   ├─ 日付: データ型で自動判定
 │   │   → 型=date + yyyyMMdd → 汎用日付ドメイン
 │   │   → 型=string + yyyy/MM等 → 個別ドメイン定義必要
 │   │   → 汎用に合わない形式 → 個別ドメイン定義必要
 │   └─ 該当すれば終了
 │
 ├─ 大分類判定
 │   → 不一致ならアウト
 │
 ├─ 桁数一致判定（最重要・大前提）
 │   → 型＋桁数が不一致なら即アウト
 │   → 日本語がどれだけ似ていても型桁不一致なら一致なし
 │
 ├─ テキストタイプで絞り込み（画面項目定義のみ）
 │
 ├─ C方式: 項目名の部分一致＋同義語辞書で材料収集
 │
 └─ B方式: LLMに材料を渡して最終判定
      → 確定 / 候補提案 / 一致なし
```

### 3-2. 型の大分類マッピング

| 大分類 | 画面項目定義の「型」 | テーブル定義の「データ型」 | ドメイン一覧の「データ型」 |
|--------|---------------------|------------------------|------------------------|
| 文字列系 | テキスト、テキストエリア、テーブルカラムテキスト等 | CHAR, VARCHAR | 半角文字、半角英字、半角数字、半角カナ、半角英数字、半角英数字記号、全角文字、全角英字、全角数字、全角ひらがな、全角カタカナ、全角英数字、全角英数字記号、全半角混合 |
| 数値系 | 数値 | NUMBER | 数値（整数）、数値（少数） |
| 日付系 | 日付 | DATE, TIMESTAMP | 日付 |
| 真偽値系 | チェックボックス | ― | 真偽値 |
| コード系 | コンボボックス、ラジオボタン | ― | コード |
| バイナリ系 | ― | RAW, ROWID | ― |

- 画面項目定義の型は多種多様で完全なマッピングは不可能
- **型は大分類レベルで参考にし、桁数での判断をメインとする**

### 3-3. テキストタイプ → ドメインデータ型の対応

| 画面テキストタイプ | ドメインデータ型の候補 |
|-------------------|---------------------|
| 半角英字 | 半角英字 |
| 半角数字 | 半角数字 |
| 半角英数字 | 半角英数字 |
| 半角カナ文字 | 半角カナ |
| 半角文字 | 半角文字、半角英数字記号 |
| 全角文字 | 全角文字、全角ひらがな、全角カタカナ等 |
| 全半角混合 | 全半角混合 |
| その他 | 全候補から桁数で判定 |

- テーブル定義にはテキストタイプがないため、大分類＋桁数のみで判定（精度はやや低い → LLM補助が有効）

### 3-4. 桁数照合の対応関係

#### 文字列系

| 画面項目定義 | ドメイン一覧 |
|-------------|-------------|
| 最大桁 | 最大文字数 |
| 最大バイト数 | 最大バイト長 |

| テーブル定義 | ドメイン一覧 |
|-------------|-------------|
| Length | 最大文字数 or 最大バイト長 |

#### 数値系

| 画面項目定義 | ドメイン一覧 |
|-------------|-------------|
| 最小値 | 最小値 |
| 最大値 | 最大値 |

| テーブル定義 | ドメイン一覧 |
|-------------|-------------|
| 全体数値 | 整数部桁数 |
| 少数桁 | 小数部桁数 |

#### 外部コード

| 画面項目定義 | ドメイン一覧 |
|-------------|-------------|
| 外部コード | 参照外部コード |

### 3-5. 項目名の比較ルール

- **数字は除去して比較**（「ああ1」と「ああ2」→「ああ」と「ああ」）
- 型＋桁数一致が大前提。不一致なら項目名は見ない

### 3-6. 日本語類似度判定（C→Bパイプライン）

#### C方式（前処理・材料収集）
- 接頭辞・接尾辞の部分一致
- 同義語辞書（YAML設定ファイルで外出し）で判定
  - 例: 金額≒代金、名称≒名前、番号≒No 等
- 部分一致率、同義語ヒット有無、特殊パターン判定結果を収集

#### B方式（LLM最終判定）
- C方式が集めた材料を受け取り、意味的類似度を最終判断
- バッチで投げてコスト最適化
- LLM判定結果は「候補提案」として出力（自動確定はしない）

### 3-7. 特殊パターン

| パターン | 条件 | 出力 |
|----------|------|------|
| フラグ | 項目名に「フラグ」含む + boolean/0,1 | 「以下から選択: 0/1, 0/9, null/1, スペース/1」 |
| コメント | 項目名に「コメント」含む | 「改行あり/なしを確認して選択してください」 |
| 補記 | 項目名に「補記」含む | コメントと同様 |
| 日付（汎用） | 型=date + yyyyMMdd | 汎用日付ドメイン自動割当 |
| 日付（個別） | 型=string + yyyy/MM等、汎用に合わない形式 | 個別ドメイン定義必要 |

## 4. 設定ファイル（YAML外出し）

以下は設定ファイルで管理し、コード内定数にしない：

- **同義語辞書**: 項目名の日本語同義語ペア
- **型の大分類マッピング**: 画面型・テーブル型・ドメイン型の対応表
- **テキストタイプ→ドメインデータ型マッピング**
- **特殊パターンの定義**: フラグ・コメント・補記・日付の条件と出力
